## 🔬 What I Work On

**@ Pfizer** — Generative and Agentic AI Engineer (PSSM). Building AI-driven solutions across pharmaceutical workflows, clinical data pipelines, and regulatory intelligence using LLMs, RAG, and multimodal systems.

**Outside work — research and build across:**

- 🧠 **LLM Engineering** — LoRA/QLoRA fine-tuning, activation tracing, mechanistic interpretability, PLE architectures on Gemma 4 E4B
- 🔍 **RAG Systems** — Production-grade retrieval pipelines, hybrid search, agentic retrieval operating systems
- 🤖 **AI Agents** — Multi-agent orchestration, deterministic execution replay, causal audit trails for agent behaviour
- 🏥 **Healthcare AI** — Clinical NLP, medical imaging, drug entity extraction, pharma regulatory intelligence
- 🗺️ **Codebase Intelligence** — Researching the hidden cost of AI-generated code in engineering teams
